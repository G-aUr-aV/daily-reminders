# Daily Reminders

## Direction

Use Android Material 3 controls with ink-neutral surfaces, a cool blue accent, and system typography. Keep light and dark equally complete. Accent belongs to Add, Save, selection, and keyboard focus. List rows use thin separators and at least 48 dp touch targets.

## Screens

- **Today** shows one date, its day type, and a compact agenda. The first screen starts with reminders or a way to create one.
- **Reminders** lists editable schedules with a short description. Sample routines and archived reminders sit below the active list.
- **New reminder / Edit reminder** shows title, time, repeat, alert and a fixed Save. Most changes take one save. Details and sound are disclosed on demand.
- **History** shows recorded occurrences by day. The latest meaningful result is the summary. Tap to see the underlying alert sequence. Export saves an iCalendar file using Android’s document picker.

Ensure Save clears the gesture bar and keyboard. Allow text to wrap and scroll at 320 dp with 200% text. Verify rendered Compose screens and an in-place update certificate match before handing off.
