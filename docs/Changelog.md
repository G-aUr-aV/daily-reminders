# Changelog

## 0.8.0

- Today shows daily progress. The editor includes a 30-minute shortcut, and the app, alarm screen, launcher and widget share a new light and dark palette.
- Done is available on the locked routine alarm and on actionable redacted notifications. Stop silences an alarm and Snooze reschedules it. Reading rituals keep their separate round tracking.
- Removed the optional draw-over-other-apps permission. Unlocked ringing reminders use Android notification controls.
- Added an unsigned Play App Bundle build targeting Android 16.

## 0.7.0

- Moved reminder plans, completion history, and live alarm state to Room. Existing data is imported on first use.
- Added password-protected portable backups for reminders, history, and imported alarm sounds under **Settings → Data & privacy**.

See the [development and sideloading guide](development.md#update-and-recover) for upgrade and recovery steps.
