# Changelog

## Unreleased

## 0.7.2

- Open Clone reminder and other actions from the reminder list.
- Edit reminders in a compact settings layout with expandable details and wrapping titles at large text sizes.

## 0.7.1

- Clone active and archived reminders into editable copies with fresh activity history.
- Automatically archive completed one-time reminders and reopen them when completion is undone.
- Keep logged outcomes visible on their original day after archiving a reminder.

## 0.7.0

- Moved reminder plans, completion history, and live alarm state to Room. Existing data is imported on first use.
- Added password-protected portable backups for reminders, history, and imported alarm sounds under **Settings → Data & privacy**.

See the [development and sideloading guide](development.md#update-and-recover) for upgrade and recovery steps.
